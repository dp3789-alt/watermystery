# 물때 (가제)

주인공의 핸드폰을 뒤져 사건의 진실을 쫓는 브라우저 추리 게임입니다. PC와 휴대폰 브라우저 모두에서 플레이할 수 있어요.

- 초대받은 사람만 플레이할 수 있도록 입장 비밀번호가 걸려 있어요. 스토리 데이터는 `js/story.enc.js`에 암호화되어 있습니다.
- 화면과 진행 규칙: `js/engine.js`, 사진 임시 그림: `js/art.js`, 비밀번호 화면: `js/gate.js`
